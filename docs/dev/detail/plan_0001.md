# plan_0001 - OpenAI 연동 및 라우팅 이슈 점검

## Goal

- OpenAI 모델 연동 실패 원인 파악 및 관련 설정/스크립트 결함 수정
- 라우팅 로직의 모델 지원 범위 확장

## Scope

- In: `bin/project`, `src/llm_gateway/extensions/routers/simple_router.py`, `.env` 설정 검증
- Out: 신규 Provider 추가 (OpenAI/Gemini 외)

## Implementation Plan

- Step 1: `bin/api_test` 파일 존재 여부 확인 및 `bin/project` 내 경로 수정 (필요 시)
- Step 2: `SimpleRouter`의 모델 접두사 체크 로직에 `o1`, `o3` 등 최신 모델군 추가
- Step 3: `bin/project`의 `run-container` 명령에 `OPENAI_API_KEY` 누락 수정
- Step 4: `tests/`의 환경 변수 의존성 확인 및 Mocking 보완

## Unit Test Plan (must)

- What to test: `SimpleRouter`의 공급자 선택 로직, `OpenAIProvider` 초기화
- Test cases:
  - `gpt-4o`, `o1-preview`, `o3-mini` 모델명이 OpenAI로 라우팅되는지 확인
  - API Key 누락 시 적절한 Exception 발생하는지 확인
- Command:
  - uv run pytest tests/extensions/test_router.py

## E2E Plan (must)

- Scenario: 실제 OpenAI 모델(또는 Mock)을 통한 채팅 완료 요청
- Expected: 200 OK와 함께 유효한 응답 메시지 수신
- How to run: `bin/project run` 후 `scripts/test_openai_real.py` 또는 `bin/project test-api` 실행
- Validation: 응답 JSON 내 `model` 필드가 요청한 모델군과 일치하는지 확인

## Done Criteria

- [ ] implementation completed
- [ ] unit tests added/updated and passing
- [ ] e2e executed and passing
- [ ] docs updated if needed
